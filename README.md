# To-Do Manager

## Project description

To-Do Manager is a small task management application built for Code2Work. Users can create, edit, delete, filter, and update the status of tasks. Tasks are saved in the browser's local storage and remain available after a page refresh.

## Technologies Used

- **Vue.js 3** (Composition API, SFC)
- **TypeScript** (Enforced types, Struct Enums)
- **Vite** (Next-generation bundler architecture)
- **HTML5 / CSS3** (Vanilla semantic elements with localized layout scopes)
- **Prettier & ESLint** (Standard styling definitions)

## Project setup

Follow these commands from your Debian or POSIX-compliant local environment terminal inside the root `to-do-manager/` folder:

# Prerequisites:
node v26.13.0
npm v11.20.0

# Commands
```bash
#Prerequisites:
node -v
npm -v

# Enter directory context
cd IDV-VUJS/day05/to-do-manager/

# Install local dependencies
npm install
```

## Running the Application

To orchestrate compilation and host a hot-reloading development preview instance locally:

```bash
# Instantiates http web development environment
npm run dev
```

The runtime container address will compile immediately (usually on `http://localhost:5173/` address).
